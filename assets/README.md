# Illustration assets for THE DAILY

The menu tries to load `assets/<name>.png` for every illustration slot.
If a file isn't here, it falls back to the built-in vector version — so you
can add these one at a time and watch each slot upgrade.

## How to export from Canva
- Export each element as a **transparent PNG** (tick "transparent background").
- Roughly **square**, ~600–800 px is plenty for print.
- Save it into this `assets/` folder using the **exact filename** below.
