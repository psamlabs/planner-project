# Fonts for THE DAILY

Drop the two display fonts here and they activate automatically
(the CSS already references them via @font-face).

Expected files (any one format works; woff2 preferred):

  Pansy.woff2   or  Pansy.ttf    →  headings  (LUNCH / DINNER / DRINKS, cover)
  Tulip.woff2   or  Tulip.ttf    →  sub-headings (cuisine card titles)

Until these exist, the menu falls back to close bubbly web fonts
(Baloo 2 for Pansy, Fredoka for Tulip) so the layout still renders.
